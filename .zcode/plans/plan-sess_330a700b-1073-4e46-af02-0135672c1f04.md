# План: Редактирование групп сервисов через UI

## Проблема
Сейчас в `MainWindow.BtnEditService_Click` (строка 364-368) стоит блок: если выбран узел с `Type == Group`, показывается MessageBox «Editing groups via UI is not supported yet. Use services.json.» и редактирование прерывается. Окно `BulkServiceWindow` используется только для **создания** групп — у него нет конструктора для редактирования.

## Решение
Группа (`Service` с `Type=Group`) хранит: `Name`, `Path`, `ChildFolders` (список подпапок), `UseChildFolderAsKeyword`, и общие настройки (Keywords, DatePatterns, CheckMode и т.д.). Children генерируются динамически в `BackupChecker.ResolveChildren` и НЕ сохраняются в JSON. Значит для редактирования достаточно открыть `BulkServiceWindow` с предзаполненными полями и обновить существующий объект.

## Изменения

### 1. `Views/BulkServiceWindow.xaml` — заголовок
- Изменить `Title="Добавить группу сервисов"` → оставить как есть, но менять из кода при редактировании

### 2. `Views/BulkServiceWindow.xaml.cs` — добавить конструктор редактирования
Добавить второй конструктор:
```csharp
public BulkServiceWindow(Service existingGroup)
{
    InitializeComponent();
    Service = existingGroup ?? throw new ArgumentNullException(nameof(existingGroup));
    Title = "Редактировать группу сервисов";
    LoadExistingGroup(existingGroup);
}
```
Новый приватный метод `LoadExistingGroup(Service s)`:
- `TxtGroupName.Text = s.Name`
- `TxtBasePath.Text = s.Path`
- `TxtChildFolders.Text = string.Join(NewLine, s.ChildFolders)`
- `TxtKeywords.Text = string.Join(", ", s.Keywords)`
- `ChkUseChildFolderAsKeyword.IsChecked = s.UseChildFolderAsKeyword`
- `TxtFileMask.Text = s.FileMask`
- `TxtDatePatterns.Text = string.Join(NewLine, s.DatePatterns)`
- числовые поля: `TxtExpectedDayOffset`, `TxtMinFilesPerDay`, `TxtMinFileSizeBytes`
- комбобоксы: `CmbCheckMode`, `CmbFileTimeSource` через `SelectComboItemByTag`
- вызов `UpdatePanels()` для переключения Regex/FileTime панелей

Важно: в режиме редактирования НЕ вызываем `LoadDefaultPatterns()`/`LoadDefaults()`, чтобы не затереть реальные значения группы значениями по умолчанию.

### 3. `MainWindow.xaml.cs` → `BtnEditService_Click` (строки 364-369)
Заменить блок блокировки на открытие `BulkServiceWindow` в режиме редактирования:
```csharp
if (selectedNode.Service.Type == ServiceTypeModel.Group)
{
    var bulkWindow = new BulkServiceWindow(selectedNode.Service);
    if (bulkWindow.ShowDialog() == true)
    {
        ApplyServiceUpdate(selectedNode.Service, bulkWindow.Service);
        _configManager.SaveConfigurationAndSync();
        LoadServices();
        StatusText.Text = "Группа обновлена";
    }
    return;
}
```

### 4. `MainWindow.xaml.cs` → `ApplyServiceUpdate` (строки 382-394)
Добавить копирование group-специфичных полей:
```csharp
target.Type = updated.Type;
target.ChildFolders = updated.ChildFolders;
target.UseChildFolderAsKeyword = updated.UseChildFolderAsKeyword;
target.Required = updated.Required;
```
