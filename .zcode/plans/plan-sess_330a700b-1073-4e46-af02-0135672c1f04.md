## 5. Экспоненциальный backoff в TelegramCommandBot

**Поле:** `private int _consecutiveErrors = 0;`

**В `StartAsync` после `PollOnceAsync`:**
```csharp
var hadError = false;
try { await PollOnceAsync(); }
catch (Exception ex) { Log(...); hadError = true; }

if (hadError) _consecutiveErrors++;
else _consecutiveErrors = 0;

var delay = _consecutiveErrors > 0
    ? Math.Min(60000, 2000 * (1 << Math.Min(_consecutiveErrors, 5)))  // 2s→4s→8s→16s→32s→60s
    : 2000;
await WaitSafe(delay, cancellationToken);
```

При недоступном API пауза растёт до 60 сек вместо спама каждые 2 сек.
